# Web Scraping компаній США за виручкою

## Опис проєкту

Цей проєкт демонструє, як за допомогою бібліотек **BeautifulSoup**, **Requests** та **Pandas** можна здійснити **web scraping** (збір даних із вебсайту) та подальшу обробку таблиць у форматі DataFrame.

Метою роботи є автоматичне отримання таблиці **найбільших компаній США за виручкою**, опублікованої у Вікіпедії, та її збереження у зручному для аналізу форматі.

> Джерело даних: [Wikipedia — List of largest companies in the United States by revenue](https://en.wikipedia.org/wiki/List_of_largest_companies_in_the_United_States_by_revenue)

---

## Використані технології

- **Python 3** — основна мова програмування;
- **Requests** — для отримання HTML-коду вебсторінки;
- **BeautifulSoup (bs4)** — для парсингу HTML та вилучення даних із таблиці;
- **Pandas** — для обробки, структурування та збереження даних у CSV-файл;
- **Jupyter Notebook** — для виконання коду, візуалізації та демонстрації результатів.

---

## Результат роботи

У результаті виконання програми отримано структуру даних із таблиці компаній США (за виручкою), яку збережено у файл `Companies.csv`.  
Вона містить такі стовпці:

- **Rank** — позиція компанії у рейтингу;
- **Name** — назва компанії;
- **Industry** — галузь діяльності;
- **Revenue (USD millions)** — річна виручка (у мільйонах доларів США);
- **Revenue growth** — зміна річної виручки у порівнянні з попереднім роком у відсотках (%);
- **Employees** — кількість працівників;
- **Headquarters** — головний офіс компанії.
